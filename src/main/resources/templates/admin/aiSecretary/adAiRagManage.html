관리자 처리 기준 안내

사용자 요청을 검토할 때 참고할 기준을 요약합니다.

  1. 사용자 요청 내용이 실제 사내 지식으로 반영 가능한지 확인합니다.
  2. 참고 URL 또는 콘텐츠 경로를 검토합니다.
  3. 문서명, 자료 유형, 카테고리를 필요 시 수정합니다.
  4. 기본 열람 권한과 최종 권한 조건을 확인합니다.
  5. 승인 시 후속 문서 등록 또는 RAG 반영 절차로 이동합니다.
  6. 반려 시 관리자 검토 메모에 사유를 남깁니다.
